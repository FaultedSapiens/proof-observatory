# Proof Observatory

Reproducibility and structural analysis infrastructure for formal mathematical proofs.

## Goal

Given a pinned paper, formalization commit, and toolchain:

- Reproduce computational artifacts
- Extract and map formal claims
- Analyze dependencies and assumptions
- Track criticisms and verification evidence
- Generate reproducibility reports
- Run Navier–Stokes / Euler simulations and visualize their behavior

## Initial Target

OpenAI's `NavierStokesAndEuler` Lean formalization.

## Status

Early development.

## Stack

C++20 · CMake · MSVC · Lean · Lake · yaml-cpp
